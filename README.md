# Sales Prediction Using Machine Learning

## Objective

Predict product sales based on advertising expenditure on TV, Radio, and Newspaper.

## Dataset

The dataset contains advertising budgets for:
- TV
- Radio
- Newspaper

Target variable:
- Sales

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib

## Machine Learning Models

1. Linear Regression
2. Random Forest Regressor

## Results

| Model | MAE | RMSE | R² |
|---|---:|---:|---:|
| Linear Regression | 1.46 | 1.78 | 0.899 |
| Random Forest | 0.62 | 0.77 | 0.981 |

## Conclusion

Random Forest performed better than Linear Regression based on MAE, RMSE, and R².

The Random Forest model achieved an R² score of approximately 0.981, showing strong predictive performance on the test data.
